# Shared instructions mirror

This is a sanitized, repository-local mirror of the shared agent agreement.
Keep changes scoped and reversible; preserve unrelated work; use accessible
Material Design 3 patterns on every user-facing surface; keep docs and CI
truthful; never expose credentials; and distinguish static checks from actual
build, runtime, packaging, and release evidence. Update the canonical shared
instructions rather than editing this mirror as a source of truth.
