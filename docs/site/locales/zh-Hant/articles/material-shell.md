# Material 應用程式外殼

Windows 外殼使用無框架視窗，配上應用程式自家標題列、精簡自繪標題控制項，
同埋 Material 指令列。主選單係一張圓角介面卡，只放一個產品標誌，並清楚分出
填滿、色調、外框同文字動作層級。只有一頁嘅工作區唔會預留重複側邊分頁欄。

啟動後編輯器會即刻可用。佢唔會顯示確認、購買、捐款、贊助、評分、評論、
升級或者其他宣傳關卡。安全指引會留喺**開啟世界**動作旁邊同離線手冊入面。
更新狀態仍然係非阻塞操作資訊，重新啟動亦一定由使用者明確控制。

## 設定同失敗情況

外殼會使用已儲存嘅亮／暗主題、密度、重點色、介面字型同縮放角色。
自繪按鈕提供 Return 同 Space 啟動、焦點、懸停、按下、停用，同埋最小目標狀態。
如果已儲存外觀值無效，現有偏好設定正規化器會退回隨程式提供嘅角色，
而唔係阻止啟動。

舊有編輯器頁面仍然有原生控制項，現正逐步遷移。共用角色投影會保持佢哋
清晰可讀，但唔代表每件編輯工具都已經完成元件級 M3 遷移。

## 保安同無障礙

視窗動作會先解析真正頂層擁有者，再執行最小化、最大化或者關閉，令裝飾性
子面板唔會收到框架操作。標題同指令控制項有無障礙名稱、清晰焦點、鍵盤啟動，
同埋有界限嘅目標。啟動路徑唔會進行購買，亦唔會儲存付款資料。
