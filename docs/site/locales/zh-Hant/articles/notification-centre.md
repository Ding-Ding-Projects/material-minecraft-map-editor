# 通知中心

通知歷史係一份有界限嘅本機記錄，收錄非阻塞資訊、進度、警告、成功同錯誤訊息。
已關閉嘅訊息仍然可以翻查，唔會抹走應用程式做過乜嘅唯一解釋。

應用程式啟動時刻意保持安靜：唔會開啟確認、購買、評論、評分、捐款、贊助
或者宣傳提示。安全指引會留喺相關情境同離線說明文件入面。有界限嘅未簽署
更新橫幅係操作狀態，唔係宣傳；只有喺有更新、已準備或者失敗時先顯示，
而且永遠唔會阻塞編輯器。

## 行為

- 最多儲存 200 筆已驗證記錄，包括 UTC 時間戳、嚴重程度、標題、正文同已關閉狀態。
- 預設用純文字搜尋標題同正文；明確正則表達式模式會先驗證模式，報告無效輸入，
  然後先會改動任何內容。
- 批次關閉會報告實際改動數目，已經關閉嘅記錄會保持原樣。
- 原生歷史清單支援多選、已本地化嘅**全部揀選**同**反轉選擇**動作，亦有
  `Ctrl+A`、`Ctrl+I` 同 `Enter` 鍵盤路徑。關閉動作仍然只會套用到
  已揀記錄或者明確選取嘅可見集合。
- JSON 同 Markdown 匯出會保留目前選擇同狀態。
- 桌面外殼會將每筆新記錄投影成非模態 Material 3 通知堆疊。資訊同成功通知
  六秒後自動關閉；警告同錯誤會保留到使用者揀**關閉**。通知唔會要求焦點，
  亦唔會阻塞目前編輯器。

## 失敗同保安界線

文字有長度限制，亦會拒絕控制字元。格式錯誤嘅持久化資料列會被忽略，
唔會當成可信內容顯示。記錄只留喺本機應用程式設定，唔會傳送到網絡服務。
