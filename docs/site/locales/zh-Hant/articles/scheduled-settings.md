# 排程設定基礎

## 範圍

Amulet 為四項現有使用者偏好設定提供本機排程合約：語言模式、主題、密度同
重點色。原生 wx 偏好設定對話框設有 **排程** 分頁，可以載入、新增、編輯、
移除同重新排列規則。持久化、驗證、配對同優先次序模組保持唔依賴 wx。
桌面外殼會喺啟動之後解析配對規則，再以有界限嘅五分鐘間隔重做；主題、密度
同重點色會經 M3 權杖層即時套用，而且唔會將遠端值寫入基礎偏好設定。

合約位於 `amulet_map_editor/api/scheduled_settings.py`，原生編輯器位於
`amulet_map_editor/api/wx/ui/preferences.py`。佢使用應用程式現有本機設定儲存庫，
唔會進行網絡存取。獨立 `amulet_map_editor.api.scheduled_sources` 模組而家提供
未來更新橋接所需嘅已驗證來源合約：本機、HTTPS API 同 Home Assistant 布林來源，
但唔會儲存權杖或者遠端值。

## 原生編輯器

「排程」分頁以清單顯示已儲存規則，規則編輯器亦留喺同一分頁。每條規則都會
顯示啟用狀態、標籤、整數優先次序、每日或者星期一至星期日選擇、可留空 ISO
開始／結束日期、24 小時制開始／結束時間，以及可留空嘅語言、主題、密度同
重點色覆寫。**新增規則**會開一條空白規則，**套用規則**會驗證並放入記憶體內
清單，**移除所選項目**會移除已揀規則。移動控制項會改變儲存次序，令相同優先
次序嘅先後結果睇得到亦改得到。偏好設定對話框嘅 **確定** 動作會驗證任何已編輯
規則，再經排程模組儲存完整清單。

切換到另一個清單列時，程式絕對唔會靜靜雞掉咗未套用表單；分頁會先要求使用者
套用佢。驗證會留喺分頁內，並使用現有語言資源本地化。如果讀得到嘅已儲存
排程包含無效或者唔支援資料，編輯器會停用、顯示確實驗證失敗，檔案亦保持不變，
唔會被一份空排程狸貓換太子。

## 版本化儲存

本機文件綱要版本係 `1`，規則上限係 256 條。每條規則都有唯一穩定識別碼、
非空白標籤、啟用狀態、由 `-10000` 至 `10000` 嘅整數優先次序、星期日子、
可留空日期邊界、本機開始／結束時間、至少一個排程值，同埋一個版本化來源物件。
現有個人檔案會遷移到明確 `local` 來源。

讀得到但有未知欄位、無效數值或者唔支援版本嘅文件會驗證失敗。咁樣可以防止
串錯字或者較新綱要被無聲當作已套用排程。遺失或者讀唔到嘅設定檔，會透過現有
設定儲存行為載入成空白版本 1 文件。

## 時間同日期語意

- 星期日子採用 Python 穩定編號：星期一係 `0`，星期日係 `6`。
- 時間使用嚴格 24 小時制 `HH:MM` 值。
- 日期邊界使用嚴格 ISO `YYYY-MM-DD` 值，並包括邊界日。
- 呼叫者會提供一個已經以設定本機時區表達嘅 `datetime`。模組唔會猜測或者
  轉換時區。
- 開始時間等於結束時間，代表全日時間窗。
- 開始時間遲過結束時間，代表跨午夜時間窗；午夜後嗰部分屬於時間窗開始嗰日嘅
  星期日子同日期。
- 結束時間唔包括在內，避免相鄰兩條規則喺邊界同一分鐘都話自己有份。

原生偏好設定編輯器會將每個輸入式 ISO 日期同 `HH:MM` 值，配對一個 M3 樣式
wx 日期或時間選擇器。輸入文字仍然係驗證同鍵盤流程嘅標準值；經選擇器揀值會
同步同一欄位，唔會暗中建立第二份排程表示。

## 決定性優先次序

所有配對規則會按整數優先次序由低至高套用。優先次序相同時，就按儲存次序套用，
所以對於兩條規則都有定義嘅任何值，較後儲存嗰條勝出。排程值可以係部分：只改
主題嘅規則，唔會刪走另一條配對規則提供嘅語言值。解析結果會按套用次序包含
配對規則識別碼，供診斷同未來介面說明使用。

## 失敗同保安邊界

建立規則、反序列化同儲存時都會驗證每個有界限欄位。無效文件會拋出
`ScheduleValidationError`；唔支援綱要版本會拋出 `UnsupportedScheduleVersion`。
wx 編輯器會以本地化行內狀態顯示呢啲失敗，同時保持無關基礎偏好設定可用。

排程唔包含權杖、網址、憑證或者遠端回應本文。wx 分頁只會編輯本機文件。
來源層會拒絕內嵌憑證、查詢字串、片段、重新導向、公網 HTTP、未知欄位、
唔支援版本、過大負載同格式錯誤實體識別碼；佢會喺三秒界限內傳回非阻塞失敗
結果，並要求呼叫者由作業系統憑證保險庫取得 Home Assistant 權杖。執行階段更新
套用亦係非阻塞：先套用本機配對，啟用中嘅 API／Home Assistant 來源再經有世代
保護嘅協調器更新，而過時或者失敗回應會保留最後有效本機狀態。外殼會喺狀態列
報告啟用中規則識別碼，關閉時停止協調器。

`ScheduledRefreshCoordinator` 為嗰個後續工作提供非阻塞執行階段原語。佢會
執行常駐更新，只經呼叫者提供嘅保險庫回呼取得 Home Assistant 權杖；當較新世代
或者關閉勝出時，佢會令遲到回應失效，而且只會為經驗證而非空白嘅結果呼叫套用
回呼。佢永遠唔會將遠端值寫入基礎偏好設定。

## 驗證

執行聚焦、唔依賴 wx 嘅測試：

```powershell
python -m unittest -v tests.test_scheduled_settings
```

測試涵蓋本機持久化、綱要版本、決定性優先次序、部分覆寫、停用規則、全日同
跨午夜時間窗、日期同星期邊界、無效輸入、未知欄位、重複識別碼，同埋拒絕
未來版本。

唔需要 wx 嘅結構合約測試亦會確認偏好設定對話框建立「排程」分頁、提供
星期／日期／時間／覆寫控制項，並經排程模組載入同儲存，而冇加入網絡或者
Home Assistant 行為。

`tests/test_scheduled_sources.py` 涵蓋網址規則、版本化白名單負載、Home Assistant
開／關行為同格式錯誤回應後備。`tests/test_scheduled_refresh.py` 涵蓋套用成功、
擷取失敗、非阻塞套用失敗、非同步取消同過時回應抑制。
`tests/test_scheduled_runtime.py` 涵蓋即時本機解析，以及格式錯誤已儲存排程嘅
安全失敗處理。
