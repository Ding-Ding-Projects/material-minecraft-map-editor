# 共用 School mode

School mode 係所有 Amulet 使用者介面共用嘅本機顯示開關。使用者可以重新命名，
佢亦會獨立於一般外觀偏好設定持久化；只有驗證本機設定嘅解鎖憑證之後先可以停用。

## 行為

- 啟用時需要 4–128 個字元嘅解鎖憑證。
- 憑證只會以加鹽 PBKDF2-HMAC-SHA256 驗證器形式，儲存喺共用本機設定記錄
  `shared_school_mode`；原始值永遠唔會寫入偏好設定、匯出、記錄或者原始碼。
- 啟用期間，`presentation_preferences()` 會強制使用英文、嚴肅文案程度
  (1/1)，並停用對話框表情符號。使用者之前嘅選擇仍然會儲存，解鎖後就會恢復。
- 使用者介面嘅模式名稱最多 64 個 Unicode 字元，亦會拒絕控制字元。
  重設會恢復隨程式提供嘅名稱。

## 失敗同保安界線

格式錯誤或者手動改過嘅狀態會退回隨程式提供嘅名稱同停用狀態。遺失、格式錯誤
或者唔正確嘅憑證永遠唔會解鎖模式。呢個係本機體驗鎖，唔係保安界線：刪除共用
設定記錄就會重設；設定介面接線完成時必須清楚講明呢一點。

## 原生設定介面

Material 3 偏好設定對話框嘅「外觀」分頁會顯示模式名稱、啟用狀態，同埋密碼式
憑證欄。儲存新憑證只會儲存驗證器；要離開已啟用模式就要提供目前憑證，
一般語言同外觀選擇仍然可以喺模式背後復原。

## 驗證

`tests/test_preferences.py` 會測試持久化、名稱同憑證界限、加鹽驗證、錯誤憑證
拒絕，同埋只限英文嘅強制顯示。原生控制項執行階段互動仍然需要驗證主機有 wx；
編譯同領域測試會覆蓋已交付接線。
