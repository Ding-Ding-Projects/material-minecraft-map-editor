# 外觀預設基礎

## 行為

`amulet_map_editor.api.appearance_presets` 提供一個唔依賴 wx 嘅具名外觀預設模型。
每個預設都會完整記低一套有版本嘅現有 `Preferences` 外觀欄位：主題、密度、
重點色、介面字型家族同介面縮放。套用預設時，只會經現有偏好設定 API 寫入
呢五個欄位，所以語言、幽默程度同對話框表情符號設定完全唔會郁，唔使擔心
換個顏色連說話方式都一齊搬屋。

程式庫支援不分大小寫嘅預設查找、明確取代、刪除、逐項重設，以及只重設
外觀嘅全域操作。重設值係 `AppearanceValues` 記錄嘅隨程式提供值；較廣泛嘅
`preferences.reset()` 行為維持不變。

呢個功能係持久化同驗證基礎，並唔聲稱每一個 wx 元素已經會使用每個外觀值，
亦唔會扮作每個元素已經有即時編輯器。

## 原生偏好設定整合

原生 **偏好設定 → 外觀** 分頁會將預設程式庫放喺現有主題、密度、重點色、
字型同縮放控制項旁邊。使用者可以：

- 揀一個已儲存預設，再載入對話框；
- 為目前五個外觀值命名並儲存成新預設，或者使用另外標明嘅更新動作，
  明確取代所揀預設；
- 經原生儲存／開啟對話框，將所揀預設匯出成 UTF-8 JSON，或者匯入有界限嘅
  JSON 檔案；
- 重設一個指定外觀屬性，或者一次重設全部五項外觀屬性。

字型列亦提供已安裝字型家族嘅有界限搜尋，同埋包含中日韓文字嘅即時排版範例。
揀搜尋結果會更新同一個 `ui_font` 值，即係原生選擇器同 `AppearanceValues`
本身使用嗰個；程式唔會將字型檔複製入個人檔案。重點色列保留標準 HEX 欄位，並加入 wx
顏色選擇器、RGB 同 HSL 轉換器。轉換器更新同一個持久化 `accent` 值，亦會顯示
佢同白色、黑色之間嘅 WCAG 對比度。未完成而無效嘅輸入會原封不動留低，直至
佢有效為止，所以打到一半嘅色碼唔會靜靜雞搶走目前顏色。

載入同重設只會將值暫存喺對話框。使用者按 **確定** 之後，佢哋先會進入生效中
嘅偏好設定；按 **取消** 就會保留之前持久化嘅外觀。驗證同檔案失敗會以持續顯示
嘅行內狀態文字呈現，而唔係用純通知式模態對話框攔路。如果已儲存預設資料讀得到，
但內容無效或者版本唔支援，程式庫控制項會停用，資料亦會保持原狀。

呢啲控制項只整合五個全域外觀值。佢哋唔會聲稱每一個 wx 元素都有自己嘅即時
外觀編輯器，亦唔會扮 wx 支援只屬 Word 嘅排版軸。不依賴 wx 嘅
`api.appearance_editor` 輔助功能，刻意只涵蓋呢個介面所需、可攜而有界限嘅
HEX／RGB／HSL 轉換、對比度計算同已安裝字型篩選。

## 儲存同設定

目前外觀繼續存放喺現有 `amulet_preferences` 記錄，欄位完全不變。主題同密度
常數會同個模型共用，避免可接受值各自生長、最後互不相認。

具名預設使用獨立 `amulet_appearance_presets` 記錄，綱要版本係 `1`，因此唔使
破壞現有個人檔案。最多可以儲存 100 個預設；名稱不分大小寫保持唯一，長度上限
係 64 個字元。

`save_preset(name)` 會擷取目前外觀；呼叫者亦可以改為傳入一個
`AppearanceValues` 實例。`apply_preset(name)`、`reset_property(name)` 同
`reset_appearance()` 都會傳回更新後嘅 `Preferences` 值。

## 匯出同匯入

`export_preset()` 會輸出決定性 UTF-8 JSON，綱要識別碼係
`amulet-appearance-preset`，版本係 `1`。`import_preset()` 接受文字或者 UTF-8
位元組，驗證完整綱要，並拒絕未知或遺漏欄位、不支援版本、重複名稱、控制字元、
過大字型／匯入內容、無效顏色，以及 0.8–2.0 範圍以外嘅縮放值。只有明確要求
`replace=True`，先可以取代已有預設。

## 失敗情況

- 格式錯誤嘅匯入會拋出 `AppearancePresetValidationError`，亦唔會儲存。
- 套用未知預設會拋出 `KeyError`，而且唔會更改任何內容。
- 讀得到但格式錯誤嘅儲存資料，以及唔支援嘅版本，都會以安全關閉方式處理。
  儲存功能仍然會被阻止，避免未來版本或者受損文件被無聲覆寫。
- 基礎偏好設定模型曾經接受嘅七位重點色，因為 alpha 意義含糊，擷取時會改用
  隨程式提供嘅重點色；匯入仍然只接受文件列明嘅六位或者八位格式。
- 重設未知或者非外觀屬性會拋出 `KeyError`。

## 保安考慮

匯入大小限制為 32 KiB。匯入器要求鍵值完全吻合，亦唔會實例化任意類別。
字型名稱同預設名稱都會拒絕控制字元。儲存文件會喺載入—修改—寫入之前安全關閉；
跨程序寫入仍然需要未來持久化層協調。領域模型唔會執行檔案、網絡或者 wx 操作；
原生檔案選擇器同行內狀態行為留喺偏好設定介面邊界。

## 驗證

執行：

```text
python -m unittest tests.test_appearance_presets
python -m unittest tests.test_appearance_editor tests.test_appearance_editor_ui_contract
```

聚焦測試涵蓋經現有偏好設定 API 進行嘅持久化同套用、決定性匯出／匯入、
重複項目處理、格式錯誤或未來綱要唔會被覆寫、有界限數值、舊式重點色、
受損儲存項目，以及兩種重設路徑都保留非外觀偏好設定。
`tests.test_appearance_presets_ui_contract` 會喺唔匯入 wx 嘅情況下剖析原生
偏好設定來源，守住可見控制項、領域呼叫、有界限檔案流程、無效儲存鎖定、
暫存重設同儲存時驗證。外觀編輯器測試涵蓋有界限顏色轉換、決定性對比度輸出、
已安裝字型篩選，同埋原生接線合約。
