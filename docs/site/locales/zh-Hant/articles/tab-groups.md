# 分頁同群組

桌面應用程式提供**檢視 → 分頁同群組…**，`Ctrl+Shift+F` 指令面板亦有同一個
目的地。原生 Material 3 介面預設用純文字搜尋已開啟分頁，旁邊有有界限嘅
正則表達式建立器。

管理員會持久化現有分頁合約：左／上／右／下分頁列邊緣、已釘選優先次序、
命名群組、群組成員關係，同埋目前分頁傳送。揀**啟用所選項目**會返去真正
筆記簿頁面，唔會開一個重複介面。無效正則表達式輸入會當成空結果處理，
永遠唔會改動分頁狀態。

目前筆記簿仍然係渲染同關閉／未儲存保護嘅權威來源。已儲存上／下停靠會投影到
即時 AGW 筆記簿，而左／右停靠而家會投影到真正可以用鍵盤揀選嘅 Material
側欄，鏡像顯示筆記簿頁面同目前選擇。AGW 仍然保留底下原生分頁標頭，因為
控制項冇提供受支援嘅隱藏標頭旗標；群組標頭仍然係後續工作，但已儲存探索合約
會保持完整。

管理員亦提供**關閉包含文字嘅分頁**同**關閉唔包含文字嘅分頁**。兩個動作都有
自己嘅純文字優先查詢同相鄰正則表達式建立器，關閉前會顯示可以覆核嘅數目；
除非揀咗**包括已釘選**，否則會保護已釘選分頁；而每次真正關閉都會經筆記簿
現有嘅未儲存工作否決。跳過嘅頁面會計數，唔會靜靜雞當成已關閉。

## 失敗情況同保安

- 搜尋最多 256 個字元，並喺本機求值。
- 無效模式唔會產生符合項目，亦唔會改動狀態。
- 未知或者格式錯誤嘅持久化 ID 會由 `TabWorkspace` 遷移丟棄。
- 群組同釘選改動會透過版本化應用程式設定儲存。

群組、停靠、ARIA 屬性，同埋配合軸向嘅鍵盤導覽。
