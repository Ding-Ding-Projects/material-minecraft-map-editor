# 離線說明文件瀏覽器

桌面應用程式會將 `docs/features` 功能文章打包成決定性 UTF-8 資源。
原生「說明文件」入口唔需要網絡都可以開啟文章，所以世界離線或者發行主機
連唔到時，協助仍然可用。

## 行為

- 文章會按穩定 slug 次序探索，而每筆套裝記錄都帶有來源路徑同 SHA-256 摘要。
- 瀏覽器會搜尋標題同 Markdown 正文，預設係純文字。有界限嘅
  `RegexBuilder` 模式同旗標需要明確選用。
- 功能集合內嘅文章連結會解析到另一篇已打包文章，並留喺瀏覽器入面。
  瀏覽器唔會擷取外部連結。
- 搜尋結果可以用鍵盤揀選，文章檢視亦可以捲動。

## 設定同失敗情況

喺儲存庫根目錄用以下指令重新產生套裝：

```powershell
py -3 scripts/build_docs_bundle.py
```

建置檢查會將每篇來源文章嘅 slug 同摘要，同已打包資源逐一比較。文章遺漏、
過期、格式錯誤或者未知時，會用 `DocumentationBundleError` 安全失敗；
應用程式唔會靜靜雞顯示唔完整說明。查詢模式受共用正則表達式建立器限制，
明確模式無效時會喺搜尋介面報告。

## 保安同私隱

文章內容隨程式留喺本機，唔會傳送到伺服器。瀏覽器唔會執行 Markdown、
唔會載入遙距圖片或者指令碼，只會將已驗證本機文章連結變成內部導覽事件。
說明文件模型同 wx 無關，所以測試唔使開視窗都可以驗證呢啲界線。

## 驗證

`tests/test_docs_browser.py` 會測試決定性探索、套裝完整性、純文字同明確正則
表達式搜尋、內部連結解析，同埋唔匯入 wx 都可以載入。呢啲檢查證明資料同
保安合約；原生執行階段畫面擷取係另一份證據。
