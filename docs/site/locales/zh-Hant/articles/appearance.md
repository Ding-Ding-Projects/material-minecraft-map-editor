# 外觀編輯器

原生「偏好設定」嘅「外觀」分頁，會將已儲存嘅 Material 3 主題、
密度、重點色、介面縮放比例，同埋所揀嘅已安裝字型即時套用到 wx
介面。佢亦提供有界限嘅 HEX/RGB/HSL 轉換、對比度讀數、即時字型預覽、
命名預設、逐項重設，以及全域外觀重設。

## 設定同失敗情況

數值會以版本化格式儲存喺共用偏好設定資料檔，載入時亦會正規化。
無效顏色、縮放比例或者字型值會退回隨程式提供嘅數值，唔會令啟動失敗。
平台唔支援嘅排版功能仍然會顯示並註明平台限制，唔會靜靜雞掉咗佢。

## 保安同無障礙

編輯器只接受有界限嘅本機數值，唔會由網絡下載字型或者顏色。
控制項保留鍵盤名稱、焦點、對比度，同埋最小觸控尺寸。School mode
會移除唔適用嘅語言同幽默程度控制項，同時保留之後可以復原嘅舊偏好設定。

## 驗證

執行 `python -m pytest -q tests/test_appearance_editor.py tests/test_appearance_presets.py tests/test_appearance_editor_ui_contract.py`。
原生 wx 介面另外需要 Windows 執行階段擷取路徑驗證。

## 逐元素外觀編輯

每個原生 Material 3 控制項嘅鍵盤可操作內容選單，都有一個
**編輯外觀…**項目。編輯器使用有界限而穩定嘅角色鍵值（無障礙名稱，
未命名時就用控制項類別），並儲存可攜式 M3 背景／前景 HEX 顏色、
字型大小、正常／中等／粗體字重、斜體、底線、刪除線，同埋有界限嘅字距。
留空顏色同字型大小 `0` 會繼承目前角色。**重設元素外觀**只會移除嗰個
角色覆寫。改動會儲存喺有界限嘅 `amulet_element_appearance` 資料檔，
並透過非阻塞本機歷史記錄。只屬 Word 嘅不支援排版軸仍然會顯示，
並註明平台限制，唔會靜靜雞掉咗佢。

鍵值最多 160 個字元，資料檔最多 512 個項目。格式錯誤嘅顏色或者字型
大小會安全退回繼承角色；過程唔涉及網絡或者任意類別載入。
`tests/test_element_appearance_contract.py` 會守住路徑、界限、即時套用、
重設、能力說明，同埋歷史記錄。斜體、底線同刪除線會即時套用到已編輯嘅
原生控制項。字距會保留畀支援佢嘅後端，而目前 wx 後端會清楚交代能力限制；
像素級 wx 執行階段擷取仍然只可以喺 Windows 驗證。
