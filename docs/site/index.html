GET STARTED

From download to first edit.

Three small steps keep your first session predictable.

  1. 01

    Choose a verified Windows release

    Download the unsigned Squirrel.Windows installer from a release with verified Setup.exe, RELEASES, and full package assets. Read the release notes before opening a world.

  2. 02

    Open a copy of your world

    Keep a backup, then open the copy in Amulet. The editor's page-based workspace keeps world selection and editing tools close at hand.

  3. 03

    Make one change, then export

    Target the smallest useful area, inspect the result, and save or export from the workflow that owns the change.
