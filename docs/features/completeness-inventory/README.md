# Per-surface completeness inventory

This is a **hand-written** register of the canonical universal-feature-delivery
list. It is deliberately not generated by scanning the tree for features that
exist, because a scan can only ever notice what is still present — it can
never notice a feature that a later change quietly removed. Each row below is
typed in by a human decision about what the feature *should* have, and the
regression test at `tests/test_feature_completeness_inventory.py` checks the
declared evidence against the real repository on every run.

A row marked **complete** means every evidence column resolves to a real path
in this repository and the fail-closed test enforces all of them. A row
marked **incomplete** is not swept under the rug: the test still runs and
asserts the row honestly reports what is missing, so the gap stays visible
instead of silently passing.
