# Per-surface completeness inventory

This is a **hand-written** register of the canonical universal-feature-delivery
list. It is deliberately not generated by scanning the tree for features that
exist, because a scan can only ever notice what is still present — it can
never notice a feature that a later change quietly removed. Each row below is
typed in by a human decision about what the feature *should* have, and the
regression test at `tests/test_feature_completeness_inventory.py` checks the
declared evidence against the real repository on every run.

A row marked **complete** means every evidence column resolves to a real path
in this repository and the fail-closed test enforces all of them. A row
marked **incomplete** is not swept under the rug: the test still runs and
asserts the row honestly reports what is missing, so the gap stays visible
instead of silently passing.

## Honest summary

Of the 19 tracked rows, **14 are complete** with implementation, article, localized
copy, persistence where relevant, tests, an interaction proof and capture
evidence all present and verified by the test below. **5 are recorded
incomplete**, each with the exact missing item named in the table rather than
silently omitted:

Three rows moved from incomplete to complete after this inventory was first
written, and they moved because the inventory named the gap: `locked-surfaces`
and `two-factor-authenticator` existed **only on the Pages site** with no
desktop implementation at all, which is precisely the silent delegation the
universal-delivery contract forbids and precisely what a tree-scan cannot
see — grep found the feature's name in a dozen files, every one of them a
generated catalog. `app-logo-customization` had a complete engine and no
surface to reach it from.

- `auto-updates` — missing capture evidence for the ready-to-restart banner.
- `pages-site-parity` — no headless-browser capture harness for the deployed site.
- `rich-controls` — no desktop-side proof that non-palette lists render live inline controls.
- `super-confirmation` — no dedicated desktop test for the two-key/slider gate, no capture.
- `tab-navigation` — no capture of the tab strip at every dock edge.

This file is updated whenever a row's evidence changes; the test below fails
closed if a row claims "complete" but any of its declared paths does not
actually exist.
